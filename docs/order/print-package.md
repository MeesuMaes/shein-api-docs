## 接口说明

该接口已逐步废弃，推荐优先对接【发货单维度打印面单接口】

## 请求头

- **Content-Type** `string` **必填**
- **x-lt-openKeyId** `string` **必填** — 访问用户隐私数据时的唯一权限标识 openKeyId
- **x-lt-timestamp** `string` **必填** — 请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000
- **x-lt-signature** `string` **必填** — 接口签名

## 请求参数

- **orderNo** `string` **必填** — 发货单其中一个订单号

## 响应参数

- **code** `string` **必填** — 0成功，1失败
- **msg** `string` **必填**
- **info** `object` **必填**
  - **orderNoList** `string[]` **必填** — 同个发货单的订单列表,如订单A,B一起发货,入参订单A查询,此字段会显示订单A,B
  - **packingType** `string` **必填** — 如果是包裹方式发货,pdf为包裹单. 如为箱唛发货,pdf为箱唛单
  - **url** `string` **必填** — 面单url
- **traceId** `string` — 请求的唯一标识；用于异常报错跟踪
